# Arctic Fox Labs

## AD Security Assessment

Enterprise Active Directory Security Assessment Framework.

### Features

- LDAP Signing Assessment
- Privileged Group Analysis
- AdminSDHolder Review
- DCSync Rights Detection
- Kerberos Security Checks
- AS-REP Roastable Users
- Tier 0 Inventory
- SIDHistory Analysis
- ADCS Discovery
- Trust Analysis

### Requirements

- PowerShell 5.1+
- RSAT Active Directory Module

### Quick Start

Import-Module .\ADSecurityAssessment.psm1

Invoke-ADSecurityAssessment
